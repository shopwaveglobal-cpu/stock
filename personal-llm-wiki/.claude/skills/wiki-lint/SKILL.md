# wiki-lint

wiki 상태 점검. **읽기 전용 — 어떤 파일도 수정하지 않는다.** 문제를 발견해도 고치지 말고 보고만 한다.

## 점검 항목

| 코드 | 항목 | 판정 기준 |
|---|---|---|
| L1 | 출처 없는 주장 | wiki/ 페이지의 수치·조건·결정에 `(출처: ...)`가 없음 |
| L2 | 오래된 정보 | 외부 수치(API 한도·가격 등)에 기준일이 없거나 90일 초과 |
| L3 | 충돌하는 내용 | 페이지 간 수치·조건 불일치인데 충돌 기록이 없음. index.md 충돌 현황 누락 포함 |
| L4 | 끊어진 링크 | 존재하지 않는 파일을 가리키는 링크 (raw 경로 포함) |
| L5 | 고아 페이지 | index.md에서도, 다른 어떤 페이지에서도 링크되지 않는 wiki 페이지 |
| L6 | 반복되는 오류 | errors/에 같은 원인이 2회 이상 → 재발 방지책이 안 지켜지고 있다는 신호 |
| L7 | 개념 분리 필요 | 같은 개념·수치가 3개 이상 페이지에 흩어져 있는데 concepts/ 페이지가 없음 |
| L8 | log/index 불일치 | log.md에 기록된 생성 파일이 index.md에 없거나, 그 반대. 예외: log의 `retire` 항목에서 제거로 명시된 페이지는 불일치가 아님 |

## 절차

1. wiki/index.md, log.md를 읽고 전체 페이지 목록을 만든다.
2. wiki/ 아래 모든 .md를 읽으며 위 항목을 검사한다.
3. 링크 검사: 각 페이지의 상대 경로 링크가 실제 파일을 가리키는지 확인한다.
4. raw/는 검사 대상의 "출처 실재 확인"에만 사용한다 (원본 내용 자체는 lint 대상 아님).

## 출력 형식 (lint-report)

```
# lint-report YYYY-MM-DD

## 요약
- 검사한 페이지: N개
- 발견된 문제: N건 (심각 N / 권고 N)

## 문제 목록
| # | 코드 | 심각도 | 파일 | 내용 | 권장 조치 |
|---|---|---|---|---|---|

## 문제 없음 확인 항목
- (통과한 검사 코드 나열)
```

- 심각도: **심각** = 잘못된 답변으로 이어질 수 있음 (L1, L3, L4) / **권고** = 유지보수 문제 (L2, L5~L8)
- 문제가 0건이어도 보고서는 출력한다.

## 금지

- 파일 수정·삭제·생성 (보고서를 파일로 저장하라는 명시 요청이 있을 때 tests/ 아래 저장만 예외)
- 발견한 문제를 "겸사겸사" 고치는 것
