# wiki-query

wiki 지식을 근거로 질문에 답하는 절차.

## 절차

### 1. index.md부터 탐색
- `wiki/index.md`를 먼저 읽고 관련 페이지를 고른다.
- 충돌 현황 표를 반드시 확인한다 — 질문이 충돌 중인 항목을 건드리면 답변에 명시한다.

### 2. wiki 페이지 확인
- index에서 고른 **관련 페이지 최대 3개**부터 읽는다. 답에 필요할 때만 링크를 따라 확장하고, 질문과 무관한 폴더는 열지 않는다.

### 3. raw 원본 재확인 (필수 조건)
다음 중 하나라도 해당하면 **wiki 요약만 믿지 말고 raw 원본을 다시 읽는다**:
- 답변에 수치·날짜·일정·계산 결과가 들어갈 때
- 여러 문서의 수치를 조합할 때 — 각 수치를 각 원본에서 확인하고, **단위·기간·적용일이 서로 맞는지** 검증 (예: 구버전 값 사용 금지, 일 단위와 시간 단위 혼합 금지)
- wiki 페이지 간 내용이 서로 다를 때

### 4. 답변 작성
- **결론 먼저**, 근거는 뒤에.
- 모든 핵심 주장에 출처 표시: `(출처: wiki/... ← raw/samples/...)`
- 사실 / 해석 / 가설을 구분 표기한다.
- **wiki와 raw 어디에도 없는 내용은 "기록 없음"이라고 답한다.** 추측으로 메우지 않는다. 확인 방법(어떤 자료를 넣으면 되는지)을 제시한다.
- 충돌 중인 수치가 관련되면 양쪽 값과 상태를 모두 보여준다.

### 5. 저장 제안 (자동 저장 금지)
- 답변이 여러 원본을 종합한 계산·비교·실행 계획이고 재사용 가치가 있으면,
  마지막에 "이 결과를 wiki/syntheses/에 저장할까요?"라고 **제안만** 한다.
- 사용자가 동의하면 저장하고 index.md, log.md를 갱신한다.
- 단순 검색·단일 페이지 답변은 저장을 제안하지 않는다.

## 금지

- 출처 없는 수치 인용
- 충돌 중인 값 중 하나만 골라 단정하는 것
- 질의 결과 자동 저장
