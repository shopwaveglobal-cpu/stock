# decision — 1IM Video Tool: 로컬 전용 + 원본 불변 설계

- 날짜: 2026-06-30 / 상태: 유효
- 출처: raw/inbox/2026-06-30-1im-video-tool-design.md (실제 기록)

## 배경

비전공자 대상 영상 도구 — 사용자 파일을 다루므로 데이터 손실·유출 리스크가 최우선 고려사항.

## 결정과 근거

1. **원본 절대 불변**: 덮어쓰기·삭제 금지, 출력은 별도 폴더 + 순번 충돌 회피, 출력 폴더 재처리 제외
2. **완전 로컬**: 클라우드·계정·텔레메트리·네트워크 호출 전면 배제 (개인정보 이슈 원천 차단)
3. **shell=True 금지**: FFmpeg 호출은 인자 배열만 — 한글 경로·공백·인젝션 안전
4. FFmpeg 자동 다운로드 대신 수동 동봉 — 공급망 리스크 회피, 실패는 명시적 메시지로

## 같은 철학의 결정

- "사용자 데이터를 절대 건드리지 않는다"는 원칙이 [노션 템플릿 결정](2026-06-17-notion-template-user-data-protection.md)과 동일 — 이 포트폴리오의 반복 설계 원칙
