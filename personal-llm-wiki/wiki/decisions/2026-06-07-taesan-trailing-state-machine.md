# decision — Taesan: 고정 고점 대신 트레일링 상태기계

- 날짜: 2026-06-07 / 상태: 유효
- 출처: raw/inbox/2026-06-07-taesan-design.md (실제 기록)

## 배경

"고점 대비 -50% 하락"을 판정하려면 고점이 필요한데, 과거 차트에서 고점을 사후에 고르면 사후확신 편향이 생겨 실전과 백테스트가 어긋남.

## 결정과 근거

- **저점→랠리→고점 동결→매수 대기→리셋의 트레일링 상태기계로 고점을 실시간 판정** (원본: "Taesan must avoid hindsight-based fixed highs")
- 가상 매도까지 시뮬레이션에 포함 — 매도 누적 횟수가 추가매수 기준가를 바꾸므로, 매수 알림만 필요한 스캐너도 전체 상태를 유지해야 정확함
- 확정 신호는 일봉 양봉으로만. 장중 가격은 "미확정 후보" 알림으로 구분
