# Local-first 앱 — 주식 계산기(stockcalc) 제작 노트

작성일: 2026-06-10
유형: 기능 정의 + 기술 선택 + 오류 (테스트용 가상 데이터)

## 기능 정의

- 매수 평단가 계산, 물타기 시뮬레이션, 수수료·세금 반영 수익률 계산
- 저장: 브라우저 localStorage. 서버·로그인 없음

## 기술 선택

- **단일 HTML + vanilla JS 채택** (React 미채택)
- 근거: 빌드 도구 없이 파일 1개로 배포·백업 가능, 비전공자가 유지보수하기 쉬움
- 트레이드오프: 기능이 크게 늘면 코드 관리가 어려워짐 → 화면 3개 초과 시 재검토

## 구현 이력

- v2.7 (2026-05-28): 물타기 시뮬레이션 추가
- v2.9 (2026-06-08): 계산 이력 저장 추가

## 오류 — localStorage 용량 초과

- v2.9에서 스크린샷 이미지를 base64로 이력에 함께 저장 → QuotaExceededError 발생
- 조치: 이미지 저장 기능 제거, 텍스트 이력만 저장 (v2.9.1, 2026-06-09)
- 교훈: localStorage에는 텍스트만, 이미지·대용량은 저장하지 않는다
