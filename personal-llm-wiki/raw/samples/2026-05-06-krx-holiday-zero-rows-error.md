# 오류 기록 — 휴장일에 KRX API 0건 응답으로 오발송

발생일: 2026-05-06 (임시공휴일, 휴장)
유형: 오류 기록 (테스트용 가상 데이터)

## 증상

- 휴장일인데 모니터가 정상 실행됨
- KRX 시세 API가 0건(빈 배열)을 반환
- 파이프라인이 "전 종목 거래대금 급감"으로 잘못 해석해 Telegram으로 오알림 1건 발송

## 원인

- 실행 전 휴장일 체크 로직이 없었음
- 데이터 0건일 때의 방어 로직도 없었음

## 조치 (2026-05-07 적용)

1. 실행 시작 시 KRX 휴장일 캘린더를 확인, 휴장일이면 즉시 종료
2. 조회 결과 0건이면 알림 발송을 중단하고 경고 로그만 남김

## 재발 방지 규칙

- 데이터가 0건이면 어떤 알림도 발송하지 않는다
- 새 모니터를 만들 때 휴장일 체크를 기본 포함한다
