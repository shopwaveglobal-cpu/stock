# 결정 — DART 공시 폴링 주기 10분

작성일: 2026-05-25
유형: 결정 기록 (테스트용 가상 데이터)

## 배경

DART 신규 공시를 Telegram으로 받아보려 함. 폴링 주기를 정해야 함.

## 제약 (기준일: 2026-05-25)

- DART OpenAPI 일일 한도: 키당 20,000건
- 감시 대상 공시 유형: 3종 (유형당 조회 1건)
- 폴링 시간대: 08:00~18:00 (10시간)

## 선택지

1. 1분 폴링: 하루 60 x 10 x 3 = 1,800건. 한도 여유 있으나 대부분 낭비 호출
2. 10분 폴링: 하루 6 x 10 x 3 = 180건. 한도의 1% 미만
3. 30분 폴링: 지연이 너무 큼 (공시 대응 목적에 부적합)

## 결정

- **10분 폴링 채택.** 공시는 분 단위 대응이 필요 없고, 호출량이 한도의 1% 미만이라 다른 API 사용과 충돌 없음

## 롤백

- 지연 불만이 생기면 장 시작 직후(08:00~09:30)만 1분 폴링으로 세분화
