# 결정 — 실시간 모니터 실행 환경: Cloud Run 대신 Windows Scheduler

작성일: 2026-06-01
유형: 결정 기록 (테스트용 가상 데이터)

## 배경

장중 5분 간격 실시간 모니터를 어디서 돌릴지 결정 필요.

## 선택지 비교 (기준일: 2026-06-01)

| 항목 | Cloud Run (min-instances=1) | 로컬 PC + Windows Scheduler |
|---|---|---|
| 월 비용 추정 | 약 $18 | 0원 (PC 상시 가동 중) |
| 장중 안정성 | 높음 | PC 재부팅·절전 리스크 |
| 유지보수 | 배포 절차 필요 | 파일 수정 즉시 반영 |

## 결정

- **로컬 PC + Windows Scheduler 채택.** 비용 0원이고 수정 즉시 반영이 유지보수에 유리
- 안정성 리스크는 watchdog(프로세스 감시 + 자동 재시작)으로 보완

## 롤백

- 오발송·누락이 월 2회 이상 발생하면 Cloud Run 이전을 재검토
