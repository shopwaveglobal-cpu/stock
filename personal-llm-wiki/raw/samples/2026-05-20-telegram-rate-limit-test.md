# 테스트 — Telegram 발송 한도 실측과 묶음 발송 결정

작성일: 2026-05-20
유형: 테스트 + 결정 (테스트용 가상 데이터)

## 배경

알림이 몰리는 날 Telegram 429 오류가 의심됨. 실제 한도를 테스트 채널에서 실측.

## 실측 결과 (기준일: 2026-05-20)

- 같은 채널에 연속 40건 발송 → 31건째부터 429 오류, retry_after=2초
- 공식 문서 기준 개인 채팅 초당 1건 권장 (URL: https://core.telegram.org/bots/faq)
- 메시지 1건 최대 길이 4096자

## 결정

- 알림을 건별 발송하지 않고 **점검 주기 1회당 메시지 1건으로 묶어서 발송**
- 메시지 1건에 알림 최대 20건까지 포함 (가독성 기준)
- 20건 초과분은 추가 메시지로 분할, 메시지 간 2초 대기

## 롤백

- 묶음 발송이 문제되면 건별 발송 + 1초 대기로 되돌림 (코드 플래그 BATCH_MODE=False)
